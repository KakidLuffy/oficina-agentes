# Oficina de agentes de trading (simulación)

Diez agentes con **dinero ficticio** (10 € cada uno, 100 € en total) operan con precios reales de Kraken. Desde el 11-nov-2026 solo compran BTC y ETH (antes, las 20 monedas de mayor volumen contra el euro) para pagar menos costes. Se ejecutan solos en GitHub Actions, aproximadamente cada hora, y un laboratorio prueba cada semana nuevas estrategias.

- **Panel:** https://kakidluffy.github.io/oficina-agentes/
- **Guía completa:** [LEEME.md](LEEME.md)
- **Quién hace qué y qué está permitido:** [EQUIPO.md](EQUIPO.md)
- **Parte del director:** [datos/parte_director.md](datos/parte_director.md)

No opera en ningún exchange, no usa claves y no garantiza beneficios. Un agente solo se considera evaluable con 3 semanas y 30 operaciones cerradas.
